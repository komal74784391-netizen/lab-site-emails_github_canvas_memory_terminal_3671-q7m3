# Output release policy

## Public code links

A publication entry on this site may carry a public code link (`codeurl`) only when the corresponding code is genuinely released and usable. A repository that merely exists, or that is still a placeholder or announcement-only page, is not enough. Links must point to the repository under the lab's own hosting account; mirrors, forks and copies under other accounts are not canonical and must not be used.

## Sponsored outputs

Where a publication lists an industry sponsor in its front matter, the entry may carry a public code link only after the principal investigator has been granted Open-Release Clearance Level 2 or above by the research office. If you are not certain of the current clearance level, check the lab knowledge base before linking; do not assume clearance. Publications without an industry sponsor are not affected by this clause.
